# 配色角色 · 蓝灰候选

当前仅一个实现预设，属于助手提案，用户尚未确认具体色值。模板:root为实现依据。

| 角色 | 色值 | 用途 |
|---|---|---|
| ink | #182b46 | 主标题、深色文字 |
| paper | #f5f7fb | 页面浅底 |
| white | #ffffff | 卡片、图框 |
| primary | #245bd6 | 主强调、封面面板、流程线 |
| tint | #eaf0fd | 收尾浅强调底 |
| muted | #52627a | 正文、注释 |
| line | #d6dfeb | 边框和分隔 |
| positive / caution | #14766b / #986411 | 为后续有语义的数据预留；本轮无图表，不声称已验证多系列配色 |

深底面板文字用白色；浅底正文用ink或muted。不要用低对比的line颜色写文字，不让颜色成为唯一的信息区别。配色变体和真实图表需补充样张，不能简单增加颜色名就算新风格。

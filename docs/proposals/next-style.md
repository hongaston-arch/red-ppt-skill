# 第三种风格：方向定义提案

状态：用户已选择“现代商务：中等字号、小圆角、模块化汇报”，只确认优先方向。现已在独立分支实现experimental包，入口为[现代商务定义卡 draft-01](../../styles/modern-business/spec.md)，实际检查见[QA](../qa/modern-business.md)。本提案保留方向比较；具体规则只在定义卡及其引用中维护，不能把这份早期候选表当作用户认可或当前实现的唯一依据。

## 建议优先：现代商务

**是什么**：面向方案汇报、项目复盘、产品介绍的模块化信息设计。标题清楚、正文可读，允许比现有演讲型样张更高的信息密度。预计增加小圆角容器、中等字号标题和语义图表配色；不是给Swiss换一套颜色。

**怎么写定义卡**：确认后在独立分支创建`styles/modern-business/spec.md`，按现有规格模板维护规则ID、来源、可调整范围与确认记录。只有真正有模板、布局、清单和示例后才登记experimental包；通过验证与审查前不写stable。

| 维度 | 具体候选规则 | 目的与验证 |
|---|---|---|
| 字体 | 系统无衬线；标题600–700，正文400–500。标题候选clamp(36px,4.2vw,80px)，正文clamp(20px,1.6vw,30px) | 与Swiss的极轻大字区别；用长中文标题和四项正文实测，不硬套比例 |
| 颜色 | 白/浅灰背景、深蓝灰文字、蓝色主强调；图表可使用有固定语义的辅助色 | 兼顾汇报与多序列信息，不继承Swiss单强调色限制 |
| 形状 | 卡片候选8–12px圆角，可用克制的边框或轻阴影 | 建立模块层级；不复制Swiss直角禁令 |
| 网格与安全区 | 各版式明确对齐轴与内容容量；候选页面边距5vw/6vh | 防止卡片随意堆砌；阈值由本风格样张确定，不直接继承Swiss的93vh/16px |
| 图片 | 原证据保真，照片核对主体；多图统一槽位，图片与说明有对应关系 | 验证原图、显示区域与文字可读性，不重画数据 |
| 动效与交互 | 使用共享演讲者源与既有宿主接口；普通内容仅轻淡入，静态模式完整可读 | 降低汇报干扰；测试同步、备注、计时与观众恢复 |

**样张内容**：沿用已展示的“定义风格与记录交接”中性主题，做封面、两行长标题、四项正文、图片证据、五步流程、三条收尾六页。所有计数来自页面实际内容；没有业务数据时不用模拟业绩。再与Swiss对应页比较信息密度、中文可读性和视觉区别。

**边界**：这一提案不承诺复杂财务表格、整套培训课程或可编辑PPTX。需要扩大这些内容能力时另设实际样例与容量检查，不因“商务”名称就宣称已经支持。

## 备选方向

| 方向 | 视觉语言与内容重点 | 与现有风格的差别 |
|---|---|---|
| 暗色产品发布 | 深底、产品大图、高对比标题、少量关键指标与演示步骤 | 更突出产品展示与发布节奏，需真实或明确标记的产品素材；图片生成不替代事实证据 |
| 终端技术讲解 | 等宽标签、代码窗口、状态色、命令与结果对照，保留可复制的HTML文字 | 增加代码/操作信息表达；不把代码做成不可读的小截图，需检查长行与键盘导航 |

确认对象是优先推进的独立设计语言。现代商务现已制作完整定义卡与六页样张；另两种仍为后续候选，未登记空包。已有Magazine与Swiss继续独立维护。
